# Layout Fixer — исправление раскладки

Проект на Python для Windows 10/11: исправляет текст, набранный в неверной раскладке,
по горячей клавише или кнопке. Это отдельная настольная утилита.

Примеры: `ghbdtn → привет`, `Ghbdtn → Привет`, `руддщ → hello`.
Преобразование идёт по расположению клавиш US QWERTY ↔ русская ЙЦУКЕН.
Это не переводчик и не проверка орфографии. Текущая раскладка клавиатуры не переключается.

## Быстрый запуск

1. Установите Python 3.11 или новее для Windows с python.org.
   Оставьте включёнными компоненты Tcl/Tk и Python Launcher (`py`).
2. Распакуйте архив целиком в отдельную папку.
3. Запустите `run.bat` двойным щелчком. Для обычного запуска сторонние пакеты не нужны.
   Альтернатива в терминале из папки проекта: `py -3 app.py`.

## Исправление в Word, Блокноте, браузере и других редакторах

1. Запустите Layout Fixer; его окно можно свернуть.
2. В нужной программе **выделите только ошибочный текст**, например `ghbdtn`.
3. Нажмите **Ctrl+Alt+F8** и отпустите клавиши. Выделение будет заменено на `привет`.
4. Для отмены используйте **Ctrl+Z в программе, где был заменён текст**.

Если сочетание занято, выберите в окне Ctrl+Alt+F9 или Ctrl+Alt+F10.
Направление из списка применяется и к горячей клавише, и к кнопкам.

Кнопка «Заменить в другом окне через 3 секунды» запускает отсчёт.
За это время перейдите в нужную программу и выделите текст. Утилита работает
с окном, активным по окончании отсчёта. Во время самой замены не меняйте
выделение, положение курсора и буфер обмена и не нажимайте клавиши.

## Исправление внутри приложения

Вставьте текст в большое поле и нажмите **«Заменить»**. Если в поле выделен
фрагмент, изменится только он; иначе изменится весь текст. «Отменить» возвращает
предыдущее состояние. «Копировать результат» копирует всё поле.

Автоматический режим выбирает одно направление для всего выделения по числу
латинских и русских букв. При равенстве — английская → русская. В смешанном
тексте выбирайте только ошибочный фрагмент или задавайте направление вручную.
Цифры, переносы строк и эмодзи сохраняются. Знаки пунктуации преобразуются по
клавишам: например, английская точка превращается в русскую `ю`. Это ожидаемо
для текста, набранного целиком в неправильной раскладке.

## Сборка EXE и установка

Сборку выполняйте **в Windows** с установленным Python:

1. Дважды щёлкните `build.bat`. Он создаст отдельное окружение `.venv`, скачает
   PyInstaller (на этом шаге нужен интернет) и соберёт `dist\LayoutFixer.exe`.
2. Можно сразу запускать этот EXE или перенести его на другой компьютер Windows
   той же архитектуры. Python на целевом компьютере не нужен.
3. Для установки запустите `install.bat`: он скопирует собранный EXE в
   `%LOCALAPPDATA%\LayoutFixer` и создаст ярлык на рабочем столе.
   Права администратора не требуются. При обновлении сначала закройте утилиту.
4. Для удаления закройте приложение, удалите указанную папку и ярлык.

Готовый EXE не включён в архив: проект создан в Linux; сборка и проверка
Windows-интеграции должны выполняться в Windows. Автозапуск не включается.
Для отключения глобального сочетания закройте окно приложения.

## Как это устроено и ограничения

- Глобальная клавиша регистрируется через Windows RegisterHotKey в отдельном
  потоке с собственной очередью сообщений. Постоянная запись ввода отсутствует.
- При замене утилита отправляет Ctrl+C, ждёт изменения буфера, преобразует текст
  и отправляет Ctrl+V. Старое содержимое буфера заменяется; исправленный текст
  остаётся в буфере. Форматирование выделения может потеряться.
- Работает с обычными редактируемыми полями, поддерживающими Ctrl+C/Ctrl+V.
  В некоторых редакторах Ctrl+C без выделения копирует целую строку — обязательно
  выделяйте нужный текст. В полях паролей, защищённых документах, играх, терминалах
  и приложениях с нестандартными сочетаниями работа не гарантируется.
- Windows может блокировать ввод в программы с повышенными правами. Проверяйте
  сначала в обычном Блокноте. Сообщение об отправке вставки не гарантирует, что
  сторонняя программа приняла её; результат также остаётся в буфере для Ctrl+V.
- Если активное окно изменилось до вставки, замена отменяется. Изменение выделения
  внутри того же окна автоматически не отслеживается.
- Никакой передачи текста по сети, истории ввода или телеметрии в коде нет.

## Структура и проверка

- `app.py` — окно, настройки, таймер и последовательность замены.
- `converter.py` — независимый алгоритм преобразования.
- `windows_api.py` — буфер обмена, горячие клавиши и ввод через Win32 API.
- `tests/` — тесты конвертации и последовательности замены с имитацией Windows.
- `run.bat`, `build.bat`, `install.bat`, `install.ps1` — запуск, сборка и установка.

Из папки проекта: `py -3 -m unittest discover -s tests -v`.
В Linux/macOS редактор может работать при наличии Tk, но глобальная замена
реализована только для Windows.

Ручная проверка в Windows: запустите приложение и обычный Блокнот; выделите
`ghbdtn`, нажмите Ctrl+Alt+F8 и проверьте `привет`; отмените через Ctrl+Z.
Повторите с `руддщ`, прописными буквами и несколькими строками, затем с кнопкой
таймера. Проверьте смену сочетания и отказ регистрации при втором экземпляре.
Затем соберите EXE и повторите проверку уже для него.
